## 🎯 Overview

Planning meals, calculating quantities, checking prices, and ensuring dietary compliance can take hours of manual work. This project leverages **CrewAI** to orchestrate a seamless, automated workflow. 

By simply providing a meal name, budget, serving size, and dietary restrictions, the system's specialized agents collaborate to generate a complete meal plan, an organized store-by-store shopping list, a budget analysis with money-saving tips, and creative recipes for leftover ingredients.

## 🤖 The AI Agent Team

The system uses a sequential multi-agent workflow to ensure each step builds upon the previous one:

1. **Meal Planner & Recipe Researcher**: Uses web search to find optimal recipes based on skill level, budget, and dietary needs. Outputs a structured `MealPlan`.
2. **Shopping Organizer**: Takes the recipe and organizes ingredients by store sections (Produce, Meat, Pantry, etc.) with estimated quantities and prices. Outputs a `GroceryShoppingPlan`.
3. **Budget Advisor**: Analyzes the shopping plan to ensure it stays within budget and provides practical money-saving tips.
4. **Leftover & Waste Reduction Specialist**: Identifies partial-usage ingredients and suggests creative bonus recipes to minimize food waste (defined using YAML config & `@CrewBase`).
5. **Report Compiler**: Consolidates all outputs—recipe, shopping list, budget tips, and leftover ideas—into one cohesive, user-friendly markdown guide.

## ✨ Features

- **Structured Output**: Uses `Pydantic` models to guarantee that AI outputs are consistently formatted, validated, and ready for programmatic use.
- **Hybrid Agent Definition**: Demonstrates both pure Python agent creation and YAML-based configuration (`agents.yaml`, `tasks.yaml`) for modularity.
- **Real-time Web Search**: Integrates the `SerperDevTool` for up-to-date recipe research and pricing data.
- **Dietary & Budget Compliance**: Ensures all recipes and shopping lists respect user-defined dietary restrictions (e.g., vegetarian, no nuts) and financial constraints.
- **Zero-Waste Cooking**: Proactively reduces food waste by generating secondary meal ideas from leftover ingredients.

## 🛠 Tech Stack

- **Language**: Python 3.12+
- **AI Framework**: [CrewAI](https://www.crewai.com/)
- **Data Validation**: [Pydantic v2](https://docs.pydantic.dev/latest/)
- **LLM Integration**: IBM Watsonx (Granite models) via `litellm`
- **Search Tool**: Serper API (`crewai-tools`)
- **Environment**: Jupyter Notebooks / Python scripts

## 📂 Project Structure

`config/` contains the YAML configuration files for the Leftover Manager agent and task.  
`Create_a_Structured_Meal_Grocery_Planner.ipynb` is the main notebook with Pydantic models & Crew execution.  
`leftover.py` is the @CrewBase class defining the YAML-driven Leftover Crew.  
`meals.json`, `shopping_list.json`, `shopping_guide.md`, and `nutrition_analysis.md` are example outputs generated by the system.

## 🚀 Getting Started

### Prerequisites

You will need API keys for the tools used in this project:
- **Serper API Key**: Get one for free at [serper.dev](https://serper.dev/)
- **IBM Watsonx / LLM API Key**: (Or modify the code to use OpenAI/Anthropic via CrewAI's `LLM` class).

### Installation

1. Clone the repository:
   git clone https://github.com/yourusername/crewai-grocery-planner.git
   cd crewai-grocery-planner

2. Install the required dependencies:
   pip install crewai crewai-tools langchain langchain-community pydantic litellm

3. Set up your environment variables in the notebook or a `.env` file:
   import os
   os.environ["SERPER_API_KEY"] = "your_serper_api_key_here"
   os.environ["WATSONX_API_BASE"] = "https://us-south.ml.cloud.ibm.com"
   os.environ["WX_PROJECT_ID"] = "skills-network"

## 💻 Usage

Open the main Jupyter Notebook (`Create_a_Structured_Meal_Grocery_Planner.ipynb`) and run the cells sequentially. 

To execute the complete five-agent workflow, run the final `kickoff` command:

complete_result = complete_grocery_crew.kickoff(
    inputs={
        "meal_name": "Chicken Stir Fry",
        "servings": 4,
        "budget": "$25",
        "dietary_restrictions": ["no nuts", "low sodium"],
        "cooking_skill": "beginner"
    }
)
